# Rust diagnostic repair

Use the exact compiler error, current declaration and affected call sites. Repository contracts and compiler evidence outrank generic guidance. This is an original compact adapter, with upstream references pinned in execution.lock.json; it does not install another router or subagent workflow.

- ownership errors (for example E0382/E0597): read references/ownership.md.
- incompatible error propagation or lost error identity: read references/error-handling.md.
- Send/Sync errors or demonstrated shared-state faults: read references/concurrency.md.

Confirm the minimal fix against domain semantics. Do not silence diagnostics using unnecessary clone/Arc/Mutex/unwrap or by weakening types. Use only the selected references, implement in the task worktree, run the affected approved check, and preserve the original output. Broader design changes return to cloud planning; never create extra agents or replace the native verification gate.
