## 从零配置的验证边界

发布前在临时目标验证基础配置＋模型映射能够生成、应用、备份且重复生成无差异；检查技能锁定版本路径与完整资源可用。技能上游版本固定在 skills.lock.json，基础 Superpowers 与 GrillMe 的关键入口与现有部署一致；审计技能为可取得的官方固定版本，未宣称与本机可能经过适配的副本逐字相同。

生成器测试不等于真实模型任务测试；目录存在不等于技能可加载；角色配置正确也不等于模型必定遵守流程。

### 实际模型闭环
